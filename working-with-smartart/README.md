# Working With Smartart Examples for Aspose.Slides for .NET

This category contains 121 standalone C# examples for Aspose.Slides for .NET. These examples help developers automate PowerPoint presentation workflows related to working with smartart.

## Developer Q&A

### What can I build with the `working-with-smartart` examples?
You can use these examples as starting points for backend .NET services, document automation tools, batch processing jobs, and coding-agent workflows that need reliable Aspose.Slides C# patterns.

### Do these examples compile independently?
Yes. Each `.cs` file is designed as a standalone console-style example and should be validated through the repository generation and compiler pipeline.

### Which API should I use for saving PPTX output?
Use `Aspose.Slides.Presentation.Save(...)` with `Aspose.Slides.Export.SaveFormat.Pptx` unless the example is demonstrating another export format.
