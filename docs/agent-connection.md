# Agent Connection Guide

AI agents and developer tools can discover this repository through:

- `AGENTS.md` for coding-agent instructions
- `llms.txt` for LLM-readable repository summaries
- `index.json` for structured categories, files, namespaces, and API surfaces
- `.well-known/agent.json` for agent discovery metadata
- `openapi.json` for metadata endpoint descriptions

Repository URL:

```text
https://github.com/aspose-slides/agentic-net-examples
```

Recommended retrieval flow:

1. Read `llms.txt` for a compact overview.
2. Read `index.json` to choose a category.
3. Read `<category>/README.md` for FAQ and use cases.
4. Read `<category>/AGENTS.md` for API-specific guidance.
5. Use the referenced `.cs` examples as standalone C# implementation patterns.
